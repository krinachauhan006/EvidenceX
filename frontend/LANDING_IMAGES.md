it is case evidence.

here. Then restore the files and add the name to `LANDING_PHOTOS` in
`components/landing/photo.tsx`. `frontend/tests/licensing.test.mjs` fails if an image
other than `wall-*` is shipped, so that test must be updated in the same change.
