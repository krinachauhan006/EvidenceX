The shipped WebP files carry no metadata (they were re-encoded with Pillow when first
built, which drops EXIF/XMP). The original source files in the owner's Downloads folder
were not inspected for embedded provenance.

To clear an image, obtain and record either a licence or written permission from its
source, or the team's own generation record, then change its Rights cell above to
"cleared" with the evidence, and its status in the test's allow-list (below) in the same
change. To remove one, delete its files and its rows here and in the allow-list; the page
falls back to the CSS artwork listed above.

## How this list is enforced

`frontend/tests/licensing.test.mjs` holds an explicit allow-list: `wall` with status
"cleared", and the six images above with status "owner-risk" (shipped at the owner's
direction, rights not verified). The tests fail if:

- any file in `public/images/landing/` is not on the allow-list, or an approved file is
  missing;
- an approved image has no row in the Shipped table, or (for the six) no provenance row
  in the table above;
- the Rights cell of an "owner-risk" image does not say "Not verified", or describes it as
  cleared;
- `LANDING_PHOTOS` or the page uses an image outside the allow-list, an image path is
  hard-coded outside `photo.tsx`, or an image moves out of its documented section.
