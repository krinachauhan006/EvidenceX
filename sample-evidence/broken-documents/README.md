# Broken and Unprocessable Evidence

This directory contains intentionally damaged, corrupted, malformed, or unsupported sample files for testing EvidenceX error handling.

These files are intended to test how the platform responds when evidence cannot be processed successfully.

### Testing scenarios

- Corrupted or damaged PDF documents
- Invalid or malformed Word documents
- Damaged image files
- Corrupted Excel spreadsheets
- Unsupported file formats
- Files with unreadable or incomplete content

**Purpose:** Validate file integrity checks, processing failure detection, error reporting, and graceful handling of unprocessable evidence.
